# Contributing / 贡献说明

**English:** This repository does not accept external contributions: Issues are
disabled and Pull Requests are not reviewed or merged. It is a personal hobby
project published for sharing. You are welcome to fork it under the MIT license
and evolve your own copy — that is the intended collaboration channel.

**中文：** 本仓库不接受外部贡献：Issues 已关闭，Pull Requests 不会被审阅或合并。
这是出品人的个人业余项目，公开仅为分享。欢迎在 MIT 许可下 fork 并自行演进——
这正是本仓库预期的协作方式。
